01この装置が何をするか

SaaSのLPで使っている「斜めの直線バー」を、曲線に置き換えたものです。抽象度・レイヤー構造・実装コストはほぼ同じまま、伝わる意味だけが変わります。

要素直線バー（SaaS）成長の曲線（教育）
形直線・鋭角曲線・右上へ立ち上がる
意味速さ・システム・精度伸びる・積み上がる・上向き
動きスクロールで加速する視差等速・減速。加速させない
色ブランド1色の濃淡3色（緑・青・黄）を低不透明度で重ねる

曲線が右上へ抜けることが本質です。左下から右上への上昇＝成長という読み方は説明不要で伝わるため、キャッチコピーに「伸びる」と書かなくても効きます。

02構造（HTML）

FVの中に背景レイヤを1つ置くだけです。SVGは1枚・パス3本。画像は使いません。

<section class="fv">
  <div class="growth is-draw" id="growth">
    <svg viewBox="0 0 1440 720" preserveAspectRatio="none" aria-hidden="true">
      <path class="r1" d="M-80 830 C 420 820, 980 640, 1560 200"/>
      <path class="r2" d="M-80 900 C 460 880, 1020 690, 1560 310"/>
      <path class="r3" d="M-80 960 C 500 945, 1060 800, 1560 440"/>
    </svg>
  </div>

  <div class="fv-inner">
    <!-- 見出し・リード・CTA -->
  </div>
</section>
  • aria-hidden="true" は必須。装飾なのでスクリーンリーダーに読ませない。
  • パスの始点 -80・終点 1560 は viewBox（0〜1440）の外側です。端を画面外に逃がすことで、線端の丸みが画面内に見えないようにしています。ここは詰めないでください。

03ジオメトリ（曲線の設計）

基準は 1440×720。3本とも「左下 → 右上」の三次ベジェで、奥にいくほど太く・上を通ります。

パス役割始点終点x=1008でのy右端
r1奥・最も太い(-80, 830)(1560, 200)547最も高い
r2中(-80, 900)(1560, 310)631中間
r3手前・最も細い(-80, 960)(1560, 440)745最も低い

見出しと重ならないことの担保： 3本とも、画面左70%（x<1008）の範囲では FV高さの76%より下を通ります。1440×720基準で、最も上を通る r1 でも x=1008 の時点で y=547 です。見出しは左上〜左中央に置く前提なので、構造的に交差しません。曲線は右端の30%で一気に立ち上がる設計で、この「後半で急に伸びる」形がそのまま成長の読みになります。

見出しを右寄せ・中央寄せにする場合、またはFVの高さを大きく変える場合は、この保証が崩れます。パスを引き直したうえで、下の検証を必ず行ってください。

この検証を必ずやること 見出しの外接矩形の中で、曲線が最も明るく／濃く出る点を拾い、文字色とのコントラスト比が 4.5:1 以上あることを確認する。下回るなら、パスを下げるか不透明度を下げる。太さで逃げないこと（太さを変えると装置の印象が変わる）。

04カラーと不透明度

パス色不透明度意図
r1#5E9C80（セージ）.22最も太いので最も薄く
r2#7FB4D0（スカイ）.30中間
r3#EDAE42（サン）.28細いので少し強く
地#FDFCF8 → #F6F3EC—172deg のグラデーション

ブランドカラーに置き換える場合は、3色の明度差を保つことが条件です。同じ明度の3色を重ねると、線が団子になって「上昇」が読めなくなります。明度差がとれない場合は2本に減らしてください。

05スクロールアニメーション

フェーズ1：入場ドロー（読み込み時に1回）

線が左下から右上へ「描かれて」いきます。3本を時間差でずらすことで、成長の順序が出ます。

項目値
手法stroke-dasharray / stroke-dashoffset を実長から 0 へ
長さの取得path.getTotalLength()（レスポンシブで変わるので resize 時に再計測）
duration1400ms
イージングcubic-bezier(.22, 1, .36, 1)（強い減速）
ディレイr1: 0ms ／ r2: 140ms ／ r3: 280ms
発火FVは初期表示にあるので、DOM構築直後に1フレーム空けて発火

フェーズ2：スクロール連動

FVをスクロールしている間だけ、グループ全体が静かに上へ抜けながら薄くなります。次のセクションに線がはみ出さないための処理でもあります。

p = clamp(scrollY / FVの高さ, 0, 1)

translateY = -(p × 42px)      // 上へ最大42px
opacity    = 1 - (p × 0.55)   // 最大45%まで薄くなる
加速させないこと SaaSのLPでは視差係数 0.55／0.78 で加速させていますが、この案では等速・減速のみにします。教育系で加速する背景は「急かされている」印象になり、安心感と正面から衝突します。42pxという移動量は、FV1画面ぶんスクロールしても「動いたことに気づくかどうか」の量です。それで正解です。

フェーズ3：呼吸（任意・既定はOFF）

常時ゆっくり上下する動きです。8秒周期・振幅±5px・各リボンで位相をずらします。写真を使わないFVで間が持たないときだけ有効化してください。

06レスポンシブ（＝細くする）

最重要：太さは viewBox のスケールから切り離す preserveAspectRatio="none" で伸縮させると、通常の stroke-width は横方向に引き伸ばされて線が潰れます。パスに vector-effect="non-scaling-stroke" を付けて、太さは CSS 側で完全に管理してください。これを外すと、狭い画面で線がべったり太くなります。 
.growth path{ vector-effect: non-scaling-stroke; }

.r1{ stroke-width: clamp(12px, 2.40vw, 34px); }
.r2{ stroke-width: clamp( 9px, 1.85vw, 26px); }
.r3{ stroke-width: clamp( 7px, 1.30vw, 18px); }

clamp を使うので、ブレークポイントを書かずに連続的に細くなります。下の表は実際に出る値です。

ビューポート幅r1r2r3本数Y位置
1440px（基準）34px26px18px3本0
1280px30px23px16px3本0

767px 以下——非表示2本+6%

@media (max-width:767px){
  .growth .r3{ display:none; }              /* 3本目を落とす */
  .growth svg{ transform:translateY(6%); }  /* 文字から離す */
}
@media (max-width:480px){
  .growth svg{ transform:translateY(9%); }
}

なぜ本数を減らすか： 幅が狭くなると3本の間隔が詰まり、重なって1本の帯に見えます。細くするだけでは足りません。767px以下では2本にして、間隔を確保してください。

07アクセシビリティ・パフォーマンス

  • prefers-reduced-motion: reduce で、ドローも視差も止めて完成状態を即表示する。
  • SVGは aria-hidden="true"、pointer-events:none。
  • アニメーションは transform / opacity / stroke-dashoffset のみ。top や height は触らない。
  • スクロールハンドラは {passive:true} ＋ requestAnimationFrame で1フレーム1回に間引く。
  • レイヤに will-change: transform, opacity。ただしFVを抜けたら外す（付けっぱなしはメモリを食う）。

08やってはいけないこと

  1. 見出しを横切らせない。 線が文字の裏を通ると、どれだけ薄くても読みにくくなります。パスを下げるのが正解で、不透明度をさらに下げて逃げると今度は線が見えなくなります。
  2. スクロールで加速させない。 05を参照。
  3. モバイルで太いまま出さない。 vw連動と本数削減の両方が必要です。
  4. vector-effect を外さない。 06を参照。線が横に潰れます。
  5. FVの外へ流し込まない。 .fv に overflow:hidden を必ず付ける。曲線が次のセクションに侵入すると、セクションの境界が読めなくなります。
  6. 3色の明度を揃えない。 04を参照。上昇が読めなくなります。

09JavaScript（全文）

(function(){
  var wrap = document.getElementById('growth');
  var fv   = document.getElementById('fv');
  if(!wrap || !fv) return;

  var reduce = matchMedia('(prefers-reduced-motion:reduce)').matches;
  var paths  = [].slice.call(wrap.querySelectorAll('path'));

  // --- フェーズ1：入場ドロー ---
  function measure(){
    paths.forEach(function(p){
      var len = Math.ceil(p.getTotalLength());
      p.style.setProperty('--len', len);
    });
  }
  measure();
  wrap.style.setProperty('--dur', '1400ms');

  if(reduce){
    wrap.classList.add('is-in');
  }else{
    requestAnimationFrame(function(){
      requestAnimationFrame(function(){ wrap.classList.add('is-in'); });
    });
  }

  // --- フェーズ2：スクロール連動（等速・加速なし） ---
  var SHIFT = 42;   // 上への最大移動量(px)
  var FADE  = 0.55; // 最大でどれだけ薄くするか
  var ticking = false;

  function frame(){
    ticking = false;
    if(reduce) return;
    var h = fv.offsetHeight || 1;
    var p = Math.min(1, Math.max(0, (window.pageYOffset || 0) / h));
    wrap.style.transform = 'translate3d(0,' + (-p * SHIFT) + 'px,0)';
    wrap.style.opacity   = (1 - p * FADE).toFixed(3);
    wrap.style.willChange = p < 1 ? 'transform,opacity' : 'auto';
  }
  addEventListener('scroll', function(){
    if(!ticking){ ticking = true; requestAnimationFrame(frame); }
  }, {passive:true});

  // --- リサイズ：パス実長が変わるので測り直す ---
  var rt;
  addEventListener('resize', function(){
    clearTimeout(rt);
    rt = setTimeout(function(){ measure(); frame(); }, 150);
  });

  frame();
})();

10チェックリスト（実装後）

  • 1440 / 1024 / 768 / 375px で、線が細くなっていく
  • 767px以下で3本目が消え、線が団子になっていない
  • 見出しの上を線が通っていない。コントラスト比 4.5:1 以上
  • 読み込み時に3本が時間差で描かれる
  • スクロールしても加速しない
  • 次のセクションに線がはみ出していない
  • OS設定で「視差効果を減らす」をONにすると、動かず完成状態で出る
  • ウィンドウをリサイズしてもドローが崩れない
